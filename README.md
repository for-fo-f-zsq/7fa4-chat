# [下载安装包](https://jx.7fa4.cn:9080/student-archive/zsq-7fa4-chat/-/packages)
```bash
curl -sL -o latest-linux.yml \
  "https://jx.7fa4.cn:9080/api/v4/projects/886/packages/generic/7FA4-Chat/latest/latest-linux.yml"
APPIMAGE=$(grep -E "^\s+- url:.*\.AppImage" latest-linux.yml | sed 's/.*url: *//')
curl -L -O "https://jx.7fa4.cn:9080/api/v4/projects/886/packages/generic/7FA4-Chat/latest/${APPIMAGE}"
chmod +x "${APPIMAGE}"
rm latest-linux.yml
./"${APPIMAGE}"
```

一个基于[7FA4 Chat API](https://jx.7fa4.cn:8888/article/134),使用[electron](https://www.electronjs.org/)+[VUE3](https://vuejs.org/)(vue+js+css)构建的跨平台聊天软件

目前已经完全支持：

- 发送markdown消息/文件/表情/自定义表情
- 文件通过base64直接发送，图片自动压缩至102400字符以内
- 自定义表情包：添加本地图片/动图为表情，收藏他人发送的表情
- 增量式获取消息，智能去重避免重复获取
- 获取并显示好友/群聊的信息
- 在本地存储消息，个人设置等数据
- 获取并显示自己的token/username/realname等信息
- 进行新建/离开群聊，添加/踢出成员，禁言，设置/取消管理员，转让群主(仅群主)等群操作
- Markdown渲染，支持行内公式`$...与块级公式`$...$`（KaTeX）
- 文件/图片点击在模态框中预览（图片大图、文本内容、不支持则提示）
- 长文本折叠显示"查看更多"，在模态框中展开完整内容
- 消息右键菜单：复制（图片/文件写入剪贴板）、转发、下载、收藏表情
- 拖拽消息气泡：文本消息拖到输入框编辑，拖到会话列表转发；非文本消息拖拽转发
- 会话置顶，排序按置顶>有realname>最新消息时间
- 系统通知弹窗（窗口不聚焦时新消息提醒），点击弹窗跳转到对应聊天
- Ctrl+Enter发送，Enter换行
- 自定义快捷键，可在设置中修改
- 多主题切换（22款主题），淡入淡出过渡动画
- 引用他人消息，@他人
- 个人头像默认浅灰色背景+首字符（头像上传已移除）
- 按年级显示颜色/自定义年级颜色
- 双击头像/昵称拍一拍对方
- 屏蔽群聊：退出后检测到被拉入自动退出
- 删除群聊：删除已经退出的群聊
- 消息搜索（当前会话/全局搜索），群聊解散
- 右键菜单可视化操作
- 输入草稿持久化，切换会话自动保存/恢复，会话列表显示草稿标识
- 图片粘贴发送（Ctrl+V），Enter/Ctrl+Enter 发送方式切换
- Markdown 实时预览，文件待发送队列
- @所有人功能，群聊中可 @全体成员
- 未读消息计数徽章，任务栏图标显示总未读数，全部标记已读
- 会话删除/隐藏，会话免打扰/全局免打扰开关，群聊最后消息发送者名称
- 消息删除（本地）
- 消息多选模式，批量转发/删除/收藏
- 收藏消息功能
- 消息日期分组线，代码块一键复制按钮，消息加载动画
- 通知隐私模式，通知聚合，通知声音
- 搜索关键词高亮，搜索结果分页加载
- 网络状态检测，断网提示横幅
- 字体大小调节，数据缓存管理
- 聊天记录备份/恢复（导出/导入到文件）
- 深色模式跟随系统
- 内置「工具」模块：IDE（代码编辑、C++ 本地编译判题、内置终端等）、交互式图编辑器、科学计算器
- ……
