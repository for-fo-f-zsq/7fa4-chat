常见问题

下载、安装与使用

装之前值得先看一眼的几件事。

如何校验下载的文件？

每个安装包都有固定的 SHA-256，下面按文件名列出。下载完成后先在终端算一遍， 再和列表里的值逐字比对。

  • Windows（PowerShell 或 CMD）：certutil -hashfile 7FA4-Chat-3.8.0-x64.exe SHA256
  • macOS / Linux：shasum -a 256 或 sha256sum 后接文件名

比对时只看到大小写不同是正常的；只要有一个字符不同，就说明文件在传输中被截断或替换， 请删掉重新下载。

支持哪些系统？
  • Windows 10 及以上（x64 / arm64，安装版与便携版）
  • macOS 11 及以上（Intel 与 Apple Silicon）
  • Linux：AppImage 与 deb，x64 / arm64
  • Android 8.0 及以上（arm64 APK）

桌面端用 Electron 构建，Android 端复用同一套界面，功能保持一致。

需要单独注册账号吗？

不需要。客户端直接使用 7FA4 的账号登录，用户名与密码就是平时上站用的那套， 登录后能看到的会话、群组与网页端一致。

登录页的「API 网址」保持默认即可；只有在校内等其他入口访问时才需要切换到对应线路。

收费吗？会不会有广告？

完全免费，没有广告，也没有需要付费才能解锁的功能。项目以 MIT 协议开源， 源码在 GitLab 与 GitHub 上都能看到。

服务器的构建、签名与分发开销由赞助名单里的老师和同学分担，自愿参与，不影响任何功能。

聊天记录存在哪里？换设备会丢吗？

记录保存在本机（客户端的本地数据目录里），不会打包上传到别处。 换一台设备需要重新登录，历史消息会按会话重新拉取。

客户端内置聊天记录备份与恢复，可以导出成文件带走，再在新设备上导入。

有网页版吗？能自己搭服务器吗？

有网页版， 点这里直接在浏览器里使用， 功能和客户端基本一致，适合临时换设备或者不方便安装的时候。同样用 7FA4 的账号登录， 只是会话不会缓存在浏览器里，每次打开都从服务端重新拉取。

不需要自建后端——客户端和网页版连的都是现有的 7FA4 服务。 源码以 MIT 协议开源，想自己编译也可以，但服务端不在这个仓库里。

遇到问题或者想提建议？

可以直接通过本站的 在线意见反馈 提交（支持直接粘贴截图，无需额外登录账号），也可以在 GitHub Issues 或 GitLab 议题 反馈。描述问题时附上系统版本、客户端版本和复现步骤，会更好定位。
